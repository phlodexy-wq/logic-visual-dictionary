# 論理学ビジュアル辞書

HTML・CSS・JavaScriptだけで動く、論理学の用語と図・表を連動させたミニアプリです。外部ライブラリやサーバーは必要ありません。
ホーム画面、4つの章、用語辞書は別ページで、共通のCSS・JavaScript・ナビゲーションを利用します。インラインフレームは使いません。

## 章

1. オイラー図：閲覧モードで開き、編集画面から名前付きの図を作成できます。例文と説明文は別々に保存され、閲覧時は説明文を開閉できます。交差・包含・分離・同一・三項の基本図形を選び、円の内側を塗り、×・S・M・Pを図上の任意の位置に配置できます。ブラウザーに自動保存され、JSONの書き出し／読み込みも可能です。読み込み時は同一ID・同一内容をスキップし、IDまたは名前の重複は一覧に表示します。重複がある間はJSONを書き出せません。保存データはページのURLとブラウザーごとで、GitHubにはJSONを手動で保管します。
2. 真偽の表：A・E・I・Oの伝統的な対当関係を図で表示します。
3. 真理表：連言・選言・含意・同値の真理値を確認できます。
4. タブロー法：妥当な推論と妥当でない推論の枝分かれを例示します。

用語辞書は枠付きカードのフレームで、選んだ用語に応じて章や図・表の表示が連動します。

## ページ構成

- `index.html`：ホームと章へのリンク
- `chapters/euler.html`：名前付きの図を作成し、基本図形・塗り・×・S/M/Pの位置を編集するオイラー図
- `chapters/opposition.html`：AEIOの対当関係
- `chapters/truth-table.html`：論理演算の真理表
- `chapters/tableau.html`：タブロー法の例
- `dictionary.html`：用語辞書の一覧
- `assets/`：全ページ共通のスタイルと動作

## 動かし方

`index.html` をブラウザーで開きます。

## GitHub Pagesで公開する場合

GitHub Pagesを有効にすると、リポジトリのURLがホームページになります。章ページや辞書へは画面上部のナビゲーションから移動できます。
